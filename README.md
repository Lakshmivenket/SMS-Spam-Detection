
# SMS Spam Detection System

## Project Description

This project is a machine learning-based application used to classify SMS messages as Spam or Not Spam.

## Features

- SMS message classification
- Spam and Not Spam prediction
- Machine learning model training
- Text message analysis
- Trained model saved for reuse
- SMS dataset processing

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Machine Learning

## How to Run

1. Install the required libraries: `python -m pip install pandas scikit-learn`
2. Train the model: `python train_model.py`
3. Run the application using the command appropriate for your `app.py`.
4. If the application uses Streamlit, run: `python -m pip install streamlit` and `python -m streamlit run app.py`

## Project Type

Machine Learning and Text Classification
